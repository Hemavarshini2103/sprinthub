# SprintHub – Project Management System

SprintHub is a project management application where managers can create projects, assign tasks to employees, and track task progress.

## Features

- User registration and login
- JWT-based authentication
- BCrypt password encryption
- Role-based access control
- Manager and Employee dashboards
- Project management
- Task creation and assignment
- Task status tracking
- Employee task access control
